# Tina Conseil

A bilingual static website for a consulting profile, implemented in HTML with supporting visual assets and legal pages.

## Structure

- [index.html](index.html): French entry point.
- [en/index.html](en/index.html): English entry point.
- Privacy and legal-notice pages are maintained in both language trees.

## Local preview

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. No JavaScript build pipeline is required.
